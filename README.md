# PrimeFXEarner API Documentation

Welcome to the official documentation for the **PrimeFXEarner 48 Hours** API.

## 🚀 Getting Started
To begin integrating, contact institutional support at **fastconnect@primefxearner.online**.

## ⚠️ Rate Limits
- **Public Data:** 100 requests/minute
- **Private Account Data:** 60 requests/minute
- **Order Execution:** 20 requests/second
